# 🌱 Agro Forte, Futuro Sustentável

Projeto desenvolvido para conscientização sobre a importância da sustentabilidade no agronegócio.

## Funcionalidades

- Página responsiva
- Cards informativos
- Quiz interativo
- Contadores animados
- Design moderno com tema agroambiental

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como executar

1. Clone o repositório:
   git clone URL_DO_REPOSITORIO

2. Abra o arquivo index.html no navegador.

## Objetivo

Demonstrar como o agronegócio pode crescer de forma sustentável, equilibrando produção e preservação ambiental.
